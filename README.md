# Code_Ticklers
COMP 3110 Project

IMPORTANT: If you are running this application on a Windows system, you will need to install the DiffUtils package from the
GnuWin32 project and set the PATH in system environment variables to "C:\Program Files (x86)\GnuWin32\bin". You can install
DiffUtils from the command line by running "winget install -e --id GnuWin32.DiffUtils".
